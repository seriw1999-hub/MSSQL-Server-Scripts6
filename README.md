# 📚 Library Database (SQL Server)

## Overview
This project demonstrates an end-to-end Library database built with Microsoft SQL Server.
It is designed using real-world database architecture principles, focusing on structure,
relationships, business logic, and data integrity.

The database models a simple library system with authors and books, including search,
analytics, and audit capabilities.
---
## Features
- Relational design with foreign keys
- Data validation using CHECK constraints
- Sample seed data
- View for combined book-author output
- Stored procedure for search functionality
- Scalar function for business metrics
- Trigger for deleted data auditing
